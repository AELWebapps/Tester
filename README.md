# 📸📄 Photo Record Generator

> 🖼️ Upload Photos • 📝 Add Captions • 🔄 Arrange • 📐 Choose Layout • 📄 Generate Word Report

A simple browser-based tool for creating **photo record reports from a Word template**.

Upload your photos, arrange them, edit captions, choose the layout, and generate the completed report.

---

## ✨ Features

- 📄 Upload a Word `.docx` template
- 📷 Upload JPG, JPEG & PNG photos
- 🖱️ Drag & drop photo upload
- 👀 Preview selected photos
- ✏️ Edit photo captions
- 🔄 Change photo order
- 🗑️ Remove unwanted photos
- 📅 Add service date
- 📍 Add location
- 📐 Multiple photo layout modes
- 📱 Responsive interface
- 💻 Runs directly in the browser

---

## 🚀 How to Use


---

## 📐 Layout Modes

### 🖼️ Standard Mode

Up to **9 photos per photo page**.

Additional pages repeat the:

- 📸 Supporting Photos heading
- 📅 Service date
- 📍 Location

### 📄 Fit All Photos on One Page

Automatically adjusts the photo:

- ↔️ Columns
- ↕️ Rows
- 📏 Sizes

to fit all selected photos onto one photo page.
